# 말랑 뽑기방 릴스 기획 (한 편, 40초)

제작은 다른 세션에서 한다. 이 문서만 읽고 바로 만들 수 있게 콘티, 화면 글자, 캡션, 자동 DM, 촬영 방법을 모두 적었다.
(2026-09-28 개정: 지금 게임에 있는 스카이 소다 화면, 3D 캡슐 기계, 촉감 4종 손맛 소리, 손으로 까는 캡슐, 쿠폰 링크를 반영했다.
 훅은 **시크릿 폭발 → 바로 모찌 ASMR** 순서로 정했다 — 소리 없이도 멈추게 하는 건 폭발, 덕후를 붙잡는 건 손맛.)

## 목표와 전환 구조

**목표:** 말랑이·스퀴시를 좋아하는 사람이 영상을 보고 "나도 만져 보고 싶다"고 느껴 **댓글을 남기고 링크를 받아 가게** 만든다.

```
영상 (손맛 ASMR + 뽑기 욕심) → 댓글 "말랑" → 자동 DM으로 선물 링크(1000코인) → 플레이 → 시크릿·사진 카드 재공유
```

- **링크는 댓글 키워드로 DM 발송**한다 (ManyChat 또는 Meta 자동 응답, 키워드: `말랑`).
  - 릴스 캡션의 링크는 눌리지 않고, 키워드 댓글이 쌓이면 도달도 오른다. 프로필 링크도 같은 주소로 걸어 둔다.
- **DM으로 보내는 주소는 선물 링크다:** `https://zunmal.pages.dev/?c=zun`
  - 들어오면 홈에 "선물 쿠폰이 도착했어요 · 받기"가 뜨고 오픈 기념 1000코인을 받는다(저장당 한 번). 1000코인이면 바로 10연 뽑기.
  - 그래서 CTA를 "댓글 달면 **1000코인 선물 링크**를 보내 드려요"로 쓸 수 있다 — 링크 요청 이유가 하나 더 생긴다.
- **댓글을 남길 이유는 두 겹:** ① 선물 링크 받기("말랑") ② 참여 질문(촉감 취향·최고 등급 — 게시 직후 본인 댓글로).

## 이 게임에서 사람들이 반응할 재료

영상은 전부 이 재료에서만 뽑는다. 없는 기능은 보여 주지 않는다.

| 재료 | 왜 먹히나 | 게임 속 위치 |
|---|---|---|
| **촉감 4종 손맛 + 소리** — 모찌(누르면 "스으" 공기 빠지는 소리, 손끝 자국이 1.5~3초에 스르륵 차오름, 깊이 누르면 주름) · 젤리(철벅, 놓으면 출렁이는 박자대로 뾰잉) · 쭉쭉이(끼익 늘어났다 퉁) · 찐득이(떼면 칙칙칙 + 실 가닥 늘어나다 "쩍") | 스퀴시 ASMR 그 자체. 소리 켜고 보게 되고 "폰으로 이게 돼?" 반응 | 놀이방(만지기) |
| **캡슐을 손으로 직접 까기** — 매트에 캡슐이 떨어지고 톡톡톡(또는 두 손가락 비틀기) → 딸깍 → 뚜껑이 날아가고 말랑이가 폴짝 | 언박싱 쾌감, 실제 캡슐 토이 감성 | 놀이방 |
| **3D 캡슐 기계** — 유리 돔 속 캡슐 30개가 실제로 쌓여 있고, 손잡이를 돌리면 더미가 휘저어지고 등급 색 캡슐이 굴러 나옴 | 오락실 캡슐 기계 느낌, 진짜 같음 | 뽑기 |
| **시크릿 0.05% 연출** (까만 전조 → 혜성 낙하 → 한 점 수축 → 이중 폭발 → 글자 도장) | 확률이 극악이라 "진짜 저게 뜬다고?" 충격과 욕심 | 뽑기 → 시크릿 |
| **말랑이마다 다른 3D 등장** (은하·불사조·유니콘·고래·세라핌) | 수집욕, "내가 뽑고 싶은 애" | 신화·시크릿 |
| **말랑이끼리 놀기** — 위에 쌓으면 아래 애가 "끙" 하며 땀방울, 옆에 대면 볼 비비기, 같이 졸기 | 모은 애들을 "같이 놀게" 하는 귀여움 | 놀이방 (친구 꺼내기) |
| **반짝 1%** | 같은 캐릭터인데 무지갯빛 | 모든 등급 |
| **사진 카드** (1080×1350, 이름·등급·"말랑이 3마리와 함께") | 스토리에 바로 올릴 수 있는 결과물 | 놀이방 사진 / 자랑하기 |
| **미니게임 12종** (말랑 합치기·슬라이스·새총·풍선·기차 …) | 수박게임·과일닌자·앵그리버드처럼 아는 재미 | 미니게임 |
| **무료 웹게임** (설치·가입 없음, 홈 화면 추가 가능) + **디저트 가게**(앱을 꺼 둬도 말랑이 직원이 코인을 벎) | 진입 장벽 낮음, 매일 돌아올 이유 | 전체 / 홈 |

## 공통 제작 규칙

- **규격:** 1080×1920, 30fps(3D·시크릿 구간은 60fps 권장), **총 40초 안팎**(38~42초).
- **안전 영역:** 위 250px, 아래 400px, 오른쪽 150px에는 글자를 두지 않는다 (릴스 UI에 가려짐).
- **화면 톤 = 지금 게임(스카이 소다):** 하늘색(#CFE6FF → 흰색) 바탕, 흰 카드, 딸기우유(#FF9FB8) 포인트.
  - **자막 글꼴:** 제목 느낌은 **주아(Jua)**, 작은 글자는 **나눔스퀘어라운드 ExtraBold**. 잉크색(#22304A) 글자 + 흰 알약 바탕(또는 흰 글자 + 은은한 파란 그림자). 굵은 검정 외곽선 풍선 글씨는 쓰지 않는다(예전 스타일).
- **자막:** 존댓말, 한 화면에 한 문장, 짧게.
- **소리가 절반이다.**
  - 만지기 소리(스으·철벅·끼익·칙칙·쩍)와 캡슐 딸깍·뽁을 **맨 앞에** 둔다. 음악은 그 아래로 낮게.
  - 시크릿 수축 직전 **정적 0.3~0.5초**는 음악까지 완전히 끈다.
- **정직하게:**
  - 촬영용으로 결과를 고정해 뽑은 장면을 실제 행운처럼 말하지 않는다("첫 판에 떴어요" 금지). "시크릿이 나오면 이렇게 돼요"로 쓴다. 확률 숫자는 사실이니 그대로.
  - 1000코인 선물은 실제로 쿠폰이 살아 있을 때만 말한다(`economy/config.ts`의 `COUPONS` 기간 확인).
- **40초를 버티게 하는 장치:** 3~4초마다 화면 종류를 바꾼다(손맛 → 링크 → 미니게임 → 기계 → 언박싱 → 3D → 놀이 → 암전). 소리의 결도 바꾼다(폭신 → 딸깍 → 뽁 → 폭발).

## 릴스 한 편: "확률 0.05%, 그리고 만질 수 있는 말랑이" (40초)

**한 줄 구성:** 시크릿 폭발 플래시 포워드(흑백 정지) → 모찌 손맛 ASMR → 촉감 4종 → 설치 없는 웹게임 → 미니게임으로 코인 → 3D 기계에서 캡슐 → 손으로 캡슐 까기 → 신화 3D → 말랑이끼리 "끙" → 시크릿 풀 연출 → 물음표 두 칸 + 1000코인 선물 링크 CTA.

### 훅 문구 (0~2초)

말랑이 게임이라는 것 + 끝까지 볼 이유를 2초 안에 한 번에 준다. 세 줄 구조를 지킨다.
- **맨 위 흰 알약:** 무슨 영상인지("말랑이 뽑기 게임"). 어느 안에서나 똑같이 둔다.
- **큰 글자 줄:** 희귀함을 숫자로.
- **가장 큰 레몬 글자 줄:** 결과를 숨긴 약속("이렇게 됨").

이 세 줄만 반말 밈 말투로 쓰고, 나머지 자막은 존댓말 그대로다.

**본안 (도발):** `말랑이 뽑기 게임` / **이 말랑이 뽑은 사람** / **아직 전 세계에 없음**
- "나도 첫 번째가 될 수 있다"는 욕심을 건드린다. 시크릿은 2000번에 1번이라 거짓말이 아니다.
- 34.5초 도감 물음표 "나머지 두 마리는 아직 아무도 못 봤어요"와 이어진다. 시작과 끝이 같은 이야기다.
- 24초 암전 자막 "그리고 2000번에 1번"이 훅의 답이 된다.

| 안 | 큰 줄 / 레몬 줄 | 노리는 것 |
|---|---|---|
| 확률 | **말랑이 게임 확률 0.05%** / **뜨는 순간 화면 실화임?** | 확률 숫자에 반응하는 가챠 유저 |
| 제작자 | **말랑이 게임 만들다가** / **0.05% 연출에 영혼 갈아 넣음** | "누가 만들었지" 호기심, 댓글 대화 |
| 덕후 | **말랑이 덕후가 만든 말랑이 게임** / **시크릿 뽑으면 이렇게 됨** | 스퀴시·말랑이 덕후 |
| 희귀 | **2000번에 1번 나오는 말랑이** / **뽑히면 폰이 이렇게 됨** | 폭발 장면 자체의 기대 |
| 촉감 반전 (B안 전용) | **말랑이 게임인데** / **폰으로 진짜 만져짐** | 0초에 모찌 꾹 ASMR로 시작할 때 |

- **쓰지 않는 말:**
  - "대박", "충격": 흔해서 넘긴다.
  - "무료 코인": 광고로 보인다.
  - "앱": 설치를 떠올린다.
  - "말랑 뽑기방"만 단독으로: 아직 아무도 모르는 이름이라 게임인지 안 보인다. 게임 이름은 6초 간판에서 알린다.
- **자막 위치:** 폭발 한가운데를 가리지 않게 화면 위 20~38%에 둔다. 금빛 "시크릿!!" 도장은 아래 58% 근처라 겹치지 않는다.

### "말랑이 게임"이라는 것 + 웹앱이라는 것을 알리는 장치

**말랑이 게임이라는 것**은 영상 안에서 네 번, 매번 다른 방식으로 말한다(말랑이 인형·스퀴시 영상으로 착각하지 않게).

1. **0초 훅:** 맨 위 흰 알약 "말랑이 뽑기 게임"이 폭발보다 한 프레임 먼저 뜨고, "이 말랑이 뽑은 사람"이 화면 속 말랑이를 가리킨다(위 **훅 문구**).
2. **2초:** "뽑은 말랑이는 폰으로 말랑말랑 만져요" — 장난감 영상이 아니라 게임 속 말랑이라는 것.
3. **6초:** 게임 간판 "말랑 뽑기방" 로고를 화면에 크게 + 자막에 게임 이름.
4. **36.5초 CTA:** "말랑이 모으러 오세요" + 게임 이름.
- 영상 내내 떠 있는 꼬리표도 **말랑이 웹게임**으로 쓴다(아래 2번).

**웹앱이라는 것**

"앱 설치해야 하나?"가 링크 요청을 막는 가장 큰 벽이라 영상 안에서 세 번 알린다.

1. **6~7초 — 눈으로 보여 주기:** DM 링크 탭 → 바로 게임. 앱스토어 화면이 한 번도 안 나온다는 게 핵심.
2. **영상 내내 — 작은 꼬리표:** 왼쪽 위(위 250px 아래)에 흰 알약 꼬리표 **설치 없는 말랑이 웹게임**을 0~40초 계속(작은 말랑이 얼굴 아이콘 + 글자). 딸기우유 점 하나 + 잉크 글자, 화면 글자보다 훨씬 작게.
3. **36.5초 — CTA에서 다시:** "말랑 뽑기방, 설치 없이 바로 해요".

- 캡션 첫 줄과 커버에도 "웹게임"을 넣는다.
- 쓰는 표현: "홈 화면에 추가하면 앱처럼 써요"(PWA). 쓰지 않는 표현: "앱 다운로드", "앱스토어".
- **인스타 DM 링크는 인스타 안 브라우저로 열린다.** 게임이 이를 알아채고 주요 버튼 아래에 두 줄짜리 "브라우저로 열기" 카드를 띄운다(접힌 상태).
  - 영상에는 이 중간 단계를 넣지 않는다.
  - 인스타 안에서도 게임·쿠폰·만지기는 다 된다. 다만 저장 공간이 따로라 브라우저로 옮기면 기록이 안 따라간다 → 자동 DM에 한 줄 안내(아래).

### 연결 포인트

- **0초 훅의 정지 장면 = 32초 "시크릿!!" 도장 장면**과 같은 컷을 쓴다. 시청자가 "아까 그 말랑이"라고 알아보게 하고, 24초 암전에서 "드디어 나온다"는 기대로 버티게 한다.
- **2초에 분위기를 뒤집는다.** 폭발 뒤 정적 → 폭신한 "스으" 소리. 이 대비가 두 번째 훅이다. 모찌 소리는 2.0초에 바로 시작(손가락이 닿기 전 공백 금지).
- **40초 → 0초 루프:** 끝의 흰 번쩍 한 프레임이 다시 재생될 때 0초 폭발로 자연스럽게 이어진다.
- **10~16초 기계 → 언박싱은 한 흐름.** 기계에서 떨어진 **같은 색(보라) 캡슐**이 매트에 떨어지는 것처럼 편집한다.
- **17.5초 신화는 3D 연출을 끝까지.** 여기서 "연출 진짜네"라는 신뢰가 생겨야 시크릿까지 본다.
- **21.5초 "끙"은 쉼표다.** 템포를 낮춰야 24초 암전이 세게 느껴진다. 웃음 포인트.
- **16~17.5초 등급 컷은 점점 짧게** 속도를 올리다 17.5초 신화에서 확 느려진다.

## 촬영 방법 (제작 세션용)

게임 코드는 이 저장소에 있다. 연출은 브라우저에서 코드로 그리는 것이라 **결과를 강제로 뽑거나 저장을 만들어** 녹화할 수 있다.

### 원하는 결과 강제로 뽑기

- **원리:** 가챠 엔진은 `Math.random`(`lib/rng.ts`의 `defaultRng`)을 쓰고, 1회 뽑기에 3번 부른다(희귀도, 캐릭터, 반짝).
- 뽑기 버튼을 누르는 순간에만 `Math.random`을 바꿔치기하면 결과가 고정된다. 저장만 바뀌고 서비스엔 영향이 없다.

```js
// 뽑기 화면에서 실행: seq = [희귀도, 캐릭터, 반짝]
const seq = [0.99996, 0.1, 0.5];
const orig = Math.random; let i = 0;
Math.random = () => seq[i++ % seq.length];
[...document.querySelectorAll('button')].find((b) => b.textContent.includes('1회 뽑기')).click();
Math.random = orig;
```

| 원하는 결과 | seq |
|---|---|
| 시크릿 꿈빛 유니콘 | `[0.99996, 0.1, 0.5]` |
| 시크릿 은하수 고래 | `[0.99996, 0.5, 0.5]` |
| 시크릿 프리즘 세라핌 | `[0.99996, 0.9, 0.5]` |
| 신화 은하 말랑 | `[0.997, 0.1, 0.5]` |
| 신화 불사조 말랑 | `[0.997, 0.9, 0.5]` |
| 반짝 버전 | 세 번째 값을 `0.005`로 |
| 일반 / 레어 / 에픽 / 전설 | 첫 값 `0.3` / `0.7` / `0.9` / `0.98` |

- 1회 뽑기는 기계에서 캡슐이 나오고, **기계 캡슐을 누르면 결과가 바로 열린다**(신화 이상은 전체 화면 연출). 새 말랑이는 놀이방에서 캡슐째 기다린다 → F 컷은 결과 창의 "지금 만지러 가기"로 들어가면 매트에 그 캡슐이 떨어진다.

### 촬영용 저장 만들기

`localStorage['malang-gacha-save']`에 넣고 새로고침. 현재 저장 버전은 **9**. 캡슐을 이미 연 말랑이만 놀이방에 바로 나온다(`unboxed`).

```js
const ids = ['peach-mochi', 'soda-drop', 'matcha-bean', 'bubble-tea'];
localStorage.setItem('malang-gacha-save', JSON.stringify({
  version: 9,
  state: {
    coins: 5000,
    ownedMalangs: Object.fromEntries(ids.map((id, i) => [id, { count: 1, shinyCount: 0, firstObtainedAt: Date.now() - i }])),
    partnerId: 'peach-mochi',
    unboxed: ids,           // 봉인 캡슐로 두고 싶으면 여기서 빼면 놀이방에서 캡슐로 떨어진다(F 컷)
    affection: { 'peach-mochi': 260 }, // Lv.5 이상이면 오래 누르기 = 녹아내리기 반응
    totalPulls: 10,
  },
}));
location.reload();
```

- 촉감: 복숭아 모찌 = 슬로우 라이징, 소다 방울 = 탱탱 젤리, 말차 콩 = 쭉쭉이, 버블티 말랑 = 찐득이.
- 놀이방은 들어오면 **한 마리만 크게**(가운데 고정). 두 마리 이상(I 컷)은 아래 "친구 꺼내기" 선반에서 꺼낸다.
- 도감 K 컷: `ownedMalangs`에 `dream-unicorn`만 시크릿으로 둔다.

### 녹화

- **폰 녹화가 최선이다.** 3D 기계·놀이방 3D·시크릿 연출이 실제 GPU로 60fps가 나오고, **손맛 소리가 같이 녹음된다**(이 영상의 핵심). 무음 스위치를 끄고, 효과음을 켠 채로 화면 녹화(마이크 끔 = 기기 소리만).
- 놀이방 소리는 누르는 **속도**를 따라간다: 모찌는 천천히 꾹, 젤리는 톡 치고 바로 떼기, 쭉쭉이는 천천히 멀리 당겼다 놓기, 찐득이는 오래 누른 뒤 위로 천천히 떼기(실 가닥이 제일 길게 나옴).
- 컨테이너(헤드리스)에서 찍어야 하면: Chromium이 3D를 소프트웨어로 그려 느리고, 놀이방은 성능 조절기가 곧 2D로 바꾼다.
  - 개발 서버(`npm run dev`)에서만 `localStorage['playroom-keep-3d']='1'`, `localStorage['machine-keep-3d']='1'`로 3D를 유지하고, `window.__playroomPause = true`로 순간을 멈춰 찍을 수 있다.
  - 시간 늦추기 + 프레임 캡처 → ffmpeg: `performance.now`·`setTimeout`·`requestAnimationFrame`을 k배 느리게 하는 init script, CSS 애니메이션은 `document.getAnimations()`에 `playbackRate = 1/k`. 뷰포트 `360×640`, `deviceScaleFactor: 3` → 1080×1920. 옵션 `--use-angle=swiftshader --enable-unsafe-swiftshader --ignore-gpu-blocklist`. `ffmpeg -framerate 30 -i f%04d.png -c:v libx264 -pix_fmt yuv420p out.mp4`.
  - 헤드리스는 소리가 안 담긴다. 손맛 소리 참고용 WAV는 `scripts/render-touch-sounds.mjs`로 만들 수 있지만(촉감·손짓별), **최종 소리는 폰 녹화를 쓴다.**
- **C 컷(DM → 게임)은 반드시 실제 폰.** 폰이 없으면 편집에서 모바일 브라우저 틀(주소창 `zunmal.pages.dev`)을 씌운다.
- 연출 컷·소리 타이밍은 `src/components/epic/director.ts`(감독 표) 참고. 시크릿은 게임 연출(10초)이 콘티 24~34.5초와 거의 같다 — 원속도로 쓰고 마지막 제목 카드만 0.5초 늘린다. 신화(7초)는 컷마다 앞부분만 잘라 17.5~21.5초 4초에 맞춘다(배출구 0.6 · 떠오르기 0.8 · 폭발 0.5 · 세계 1.2 · 착지+도장 0.9).

## 성과 확인

- **1순위:** 키워드 댓글 수(= 선물 링크 요청 수), DM 발송 수, 링크 클릭 수, 쿠폰 받기 수(게임 안에서는 서버가 없어 셀 수 없으니 링크 단축 서비스 클릭 수로 대신).
- **2순위:** 저장·공유 수, 3초 이탈률, 평균 시청 시간(루프 여부).
- **A/B 테스트:** 같은 편집에서 앞 2~4.5초만 바꿔 한 편 더 올린다(나머지는 그대로).
  - B안(덕후용): 0초부터 모찌 꾹 ASMR + 훅 "말랑이 게임인데 / 폰으로 진짜 만져짐" → 시크릿은 24초에 처음 등장, 끝은 모찌 꾹으로 루프.
  - 훅 글자만 바꾸는 A/B: 위 **훅 문구** 후보 표(확률·제작자·덕후·희귀)를 영상은 그대로 두고 0~2초 글자만 바꿔 올린다.
  - C안: 찐득이 실 가닥 "쩍" 클로즈업 + "이 소리 뭐예요?"
  - D안: "끙" 쌓기 클로즈업 + "밑에 애 표정 보세요"
  - 비교 기준: 3초 이탈률(훅의 힘) vs '말랑' 댓글 수(링크 요청). 덕후 유입이 목표라 댓글 수가 더 높은 쪽을 남긴다.
