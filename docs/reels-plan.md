# 말랑 뽑기방 릴스 기획

제작은 다른 세션에서 한다. 이 문서만 읽고 바로 만들 수 있게 대본, 화면 문구, 촬영 방법을 모두 적었다.

## 목표와 전환 구조

**목표:** 영상을 본 사람이 "나도 해보고 싶다"고 느껴서 **댓글을 남기고 링크를 받아 가게** 만든다.

```
영상 (궁금증 + 욕심) → 댓글 "말랑" → 자동 DM으로 게임 링크 → 플레이 → 시크릿 뽑으면 재공유
```

- **링크는 댓글 키워드로 DM 발송**한다 (ManyChat 또는 Meta 자동 응답, 키워드: `말랑`).
  - 릴스 캡션의 링크는 눌리지 않고, 키워드 댓글이 쌓이면 도달도 오른다.
  - 프로필 링크도 같은 주소로 걸어 둔다.
- **댓글을 남길 이유는 영상마다 두 겹으로 둔다.**
  1. 링크 받기 ("말랑" 댓글)
  2. 참여 질문 (몇 번째 캡슐? 어느 등급? 이름 짓기 등)
- **게임 링크 자리표시자:** `{GAME_URL}` — Cloudflare Pages 배포 주소로 채운다.

## 이 게임에서 사람들이 반응할 재료

영상은 전부 이 재료에서만 뽑는다. 없는 기능은 보여 주지 않는다.

| 재료 | 왜 먹히나 | 게임 속 위치 |
|---|---|---|
| **시크릿 0.05% 연출** (까만 전조 → 혜성 낙하 → 한 점 수축 → 이중 폭발 → 글자 도장) | 확률이 극악이라 "진짜 저게 뜬다고?" 하는 충격과 욕심 | 뽑기 → 시크릿 |
| **말랑이마다 다른 3D 등장** (은하·불사조·유니콘·고래·세라핌) | 수집욕, "내가 뽑고 싶은 애" 고르기 | 신화·시크릿 |
| **등급별 차별화** (일반 → 시크릿으로 갈수록 머신·소리·색이 화려해짐) | 대비가 한눈에 보인다 | 뽑기 결과 |
| **말랑 만지기 소리** (찰박·쭉·뽁) | ASMR, 소리 켜고 보게 됨 | 만지기 탭 |
| **반짝(shiny) 1%** | 같은 캐릭터인데 무지갯빛이라 "레어 중의 레어" | 모든 등급 |
| **귀여운 캐릭터 32종** (복숭아 모찌, 소다 방울, 달토끼 말랑, 꿈빛 유니콘 …) | 캐릭터 호감, "얘 이름 뭐예요" 댓글 | 도감 |
| **무료 브라우저 게임** (설치·가입 없음) | 링크만 누르면 바로 된다는 낮은 진입 장벽 | 전체 |

## 공통 제작 규칙

- **규격:** 1080×1920, 30fps(시크릿 연출 컷은 60fps 권장), 7~15초. 첫 1초 안에 훅.
- **안전 영역:** 위 250px, 아래 400px, 오른쪽 150px에는 글자를 두지 않는다 (릴스 UI에 가려짐).
- **글꼴:** 게임과 같은 **카페24 써라운드**. 흰 글자 + 잉크색(`#2b2233`) 외곽선 + 아래 그림자로 게임 제목과 같은 풍선 글씨.
- **자막 톤:** 존댓말 반말 섞지 말고 짧게. 한 화면에 한 문장. 이모지는 캡션에만 조금.
- **소리가 절반이다.**
  - 게임 효과음(폭발, 종소리 화음, 뽁 소리)을 살리고, 음악은 효과음 아래로 깐다.
  - 시크릿 수축 직전 **정적 0.3초**는 절대 음악으로 덮지 않는다.
- **정직하게:**
  - 촬영용으로 결과를 고정해 뽑은 장면을 "제가 첫 판에 뽑았어요"처럼 실제 행운인 척 말하지 않는다.
  - "시크릿 연출 공개", "시크릿 나오면 이렇게 돼요" 같은 표현을 쓴다. 확률 0.05%는 사실이니 그대로 써도 된다.
- **마지막 1~2초는 루프**가 되게 첫 장면과 이어 붙인다 (재생 수 증가).

## 영상 5편

우선순위는 1 → 2 → 3이다. 4·5는 반응을 보고 만든다.

### 1편. "0.05% 뜨면 생기는 일" (대표작, 13초)

**훅:** 까만 화면에 글자만. "2000번에 1번 나오는 연출이에요"

| 시간 | 화면 | 화면 글자 | 소리 |
|---|---|---|---|
| 0.0–1.0 | 완전 검정 → 가운데 별 하나 반짝 (시크릿 전조 첫 장면) | **2000번에 1번 나오는 연출** | 낮은 웅웅 (`secretTease`) |
| 1.0–2.2 | 별이 혜성처럼 떨어져 캡슐로 쾅 착지, 위아래 영화 띠 | (없음) | 쿵 |
| 2.2–4.0 | 빛 고리 세 개가 캡슐을 감싸고 빨라짐, 금이 번짐 | **소리 켜 주세요** | 차오르는 소리 |
| 4.0–4.5 | 모든 빛이 한 점으로 수축 → 정적 | (없음) | 빨려 드는 소리 → 무음 |
| 4.5–6.5 | 색 반전 한 프레임 → 폭발 → 0.3초 뒤 초신성 무지개 충격파 | (없음) | 폭발 두 번 + 종소리 화음 |
| 6.5–9.5 | 꿈빛 유니콘 등장, 무지개 아치, "시크릿!!" 한 글자씩 도장 | (게임 화면 글자 그대로) | 팡파르 |
| 9.5–13.0 | 도감 시크릿 칸: 유니콘만 채워지고 나머지 2칸은 물음표 | **나머지 두 마리는 아직 아무도 못 봤어요** → **해보고 싶으면 댓글에 '말랑'** | 여운 |

- **캡션:**
  ```
  확률 0.05%, 시크릿 말랑이가 나오면 화면이 이렇게 돼요.
  시크릿은 딱 3마리. 나머지 2마리는 직접 뽑아서 확인해 보세요.
  설치 없이 브라우저에서 바로 돼요. 댓글에 '말랑' 남기면 링크 보내 드릴게요.
  ```
- **고정 댓글:** "나머지 시크릿 2마리 연출은 완전히 달라요. 뽑으면 캡처해서 보여 주세요!"
- **루프:** 13초 도감 화면 → 다시 까만 화면으로 페이드. 루프가 자연스럽다.

### 2편. "등급 올라갈수록 연출이 미쳐 가요" (15초, 비트 컷)

**훅:** 일반 등급의 소박한 결과로 시작해 기대를 낮춘 뒤 점점 폭발시킨다.

| 시간 | 등급 | 화면 글자 |
|---|---|---|
| 0.0–1.5 | 일반 (61.95%) — 복숭아 모찌, 조용한 결과 | **일반** |
| 1.5–3.0 | 레어 (25%) | **레어** |
| 3.0–4.5 | 에픽 (9.5%) | **에픽** |
| 4.5–6.5 | 전설 (3%) — 머신 흔들림 커짐 | **전설** |
| 6.5–10.0 | 신화 (0.5%) — 불사조 말랑 3D 등장, 불꽃 날개 | **신화** |
| 10.0–15.0 | 시크릿 (0.05%) — 전조부터 초신성까지 압축 컷 | **시크릿** → **어디까지 뽑아 봤는지 댓글로** |

- 각 등급 글자 옆에 확률을 작게 붙인다. 컷은 음악 비트에 맞춘다.
- **댓글 유도:** "당신 최고 기록은? 일반/레어/에픽/전설/신화/시크릿 중 하나 댓글로" + "링크는 '말랑' 댓글".
- **캡션 첫 줄:** "일반부터 시크릿까지 한 번에 보기"

### 3편. "말랑이 만지는 소리 ASMR" (10초, 소리 필수)

**훅:** 첫 프레임부터 손가락이 말랑이를 꾹 누른다. 설명 없이 바로 소리.

- **화면:** 만지기 탭. 누르기 → 늘이기 → 튕기기를 반복하고, 말랑이 3종(달토끼, 해파리, 소다 방울)을 빠르게 바꿔 가며.
- **화면 글자:** 처음 1초에 **이어폰 끼고 보세요** 한 줄. 끝에 **친밀도 올리면 표정이 달라져요**.
- **댓글 유도:** "제일 만지고 싶은 애 골라 주세요: 달토끼 / 해파리 / 소다 방울"
- 음악 없이 게임 소리만 쓴다.

### 4편. "캡슐 3개 중 하나만 시크릿" (참여형 시리즈, 8초)

**훅:** 캡슐 세 개가 나란히 멈춰 있고 **하나에 시크릿이 들어 있어요. 몇 번?**

- 화면을 3초간 멈춰 고르게 한 뒤 영상은 결과 없이 끝낸다.
- 다음 편 첫 장면에서 "정답은 2번" + 시크릿 연출을 보여 준다.
- **댓글 유도:** 1·2·3 숫자 댓글 (가장 쉬운 댓글이라 참여율이 높다). 링크 안내는 고정 댓글로.
- ⚠️ 세 캡슐 화면은 편집으로 합성한다 (게임 안에 이런 화면은 없음). "편집 화면"임을 밝힐 필요는 없지만, 게임에 없는 기능처럼 말하지 않는다.

### 5편. "혼자 만든 게임인데 연출에 진심" (메이킹, 15초)

**훅:** **말랑이 뽑기 게임 만들었는데 시크릿 연출에만 일주일 썼어요**

- 2D 초안(예전 연출) → 3D 캡슐 → 빛 번짐 → 이중 폭발로 단계별 비교.
  - 3D 연출이 없는 2D 초안 화면은 WebGL을 끈 브라우저에서 찍으면 나온다 (아래 촬영 참고).
- **댓글 유도:** "다음에 추가할 말랑이 이름 댓글로 지어 주세요. 뽑히면 진짜 넣어요."
  - 실제로 넣을 수 있을 때만 이 문구를 쓴다.

## 게시 운영

- **순서:** 1편 → (2~3일) → 2편 → 3편 → 반응이 가장 좋은 편의 변형.
- **시간:** 평일 저녁 8~10시, 주말 오후.
- **해시태그 (5개 이내):** `#뽑기게임 #가챠 #귀여운게임 #무료게임 #말랑이`
- **첫 1시간 동안 댓글에 전부 답한다.** DM 자동 발송과 별개로 "보냈어요!" 대댓글을 달면 알고리즘에 좋다.
- **2차 확산:** 시크릿을 실제로 뽑은 플레이어의 캡처·녹화를 받아 리그램한다 (허락 받고).

## 촬영 방법 (제작 세션용)

게임 코드는 이 저장소에 있다. 연출은 브라우저에서 코드로 그리는 것이라, **특정 결과를 강제로 뽑아서 녹화**할 수 있다.

### 원하는 결과 강제로 뽑기

- **원리:** 가챠 엔진은 `Math.random`을 쓰고, 1회 뽑기에 3번 부른다 (희귀도, 캐릭터, 반짝).
- 뽑기 버튼을 누르는 순간에만 `Math.random`을 바꿔치기하면 결과가 고정된다. 저장 데이터만 바뀌고 실제 서비스엔 영향이 없다.

```js
// 페이지에서 실행: seq = [희귀도, 캐릭터, 반짝]
const seq = [0.99996, 0.1, 0.5];
const orig = Math.random; let i = 0;
Math.random = () => seq[i++ % seq.length];
[...document.querySelectorAll('button')].find((b) => b.textContent.includes('1회 뽑기')).click();
Math.random = orig;
```

| 원하는 결과 | seq |
|---|---|
| 시크릿 꿈빛 유니콘 | `[0.99996, 0.1, 0.5]` |
| 시크릿 은하수 고래 | `[0.99996, 0.5, 0.5]` |
| 시크릿 프리즘 세라핌 | `[0.99996, 0.9, 0.5]` |
| 신화 은하 말랑 | `[0.997, 0.1, 0.5]` |
| 신화 불사조 말랑 | `[0.997, 0.9, 0.5]` |
| 반짝 버전 | 세 번째 값을 `0.005`로 |
| 일반 / 레어 / 에픽 / 전설 | 첫 값 `0.3` / `0.7` / `0.9` / `0.98` |

- 코인이 모자라면 `localStorage['malang-gacha-save']`의 `state.coins`를 올린 뒤 새로고침한다.
- 도감을 비우거나 채우고 싶으면 `ownedMalangs`를 직접 편집한다.

### 녹화

- **폰 녹화가 최선이다.** 실제 GPU로 60fps가 나오고 소리도 같이 녹음된다. 가능하면 이걸 쓴다.
- 클라우드 컨테이너에서 찍어야 한다면 그 환경의 Chromium은 3D를 소프트웨어로 그려서 실시간 녹화는 끊긴다. 그러면 **시간을 늦춰 프레임 단위로 캡처**한 뒤 ffmpeg로 이어 붙인다.
  - 기존 스크립트 방식: `performance.now`, `setTimeout`, `requestAnimationFrame`을 k배 느리게 만드는 init script를 넣는다.
  - 뷰포트는 `360×640`, `deviceScaleFactor: 3`으로 두면 1080×1920이 나온다.
  - 실행 옵션: `--use-angle=swiftshader --enable-unsafe-swiftshader --ignore-gpu-blocklist`
  - 캡처한 프레임을 `ffmpeg -framerate 30 -i f%04d.png -c:v libx264 -pix_fmt yuv420p out.mp4`로 합친다.
  - 주의: CSS 애니메이션(화면 띠, 색 반전 프레임, 글자 도장)은 이 방법으로 느려지지 않는다. 필요하면 `document.getAnimations()`로 `playbackRate = 1/k`를 걸어 맞춘다.
  - 폰트는 CDN에서 오므로 막혀 있으면 로컬 woff로 라우팅한다.
- **2D 초안 화면(5편):** Chromium을 `--disable-webgl`로 띄우면 자동으로 2D 연출이 나온다.
- **소리:** 헤드리스 녹화로는 소리가 안 담긴다.
  - 폰으로 소리만 따로 녹음하거나, 스피커 출력을 녹음해 편집에서 맞춘다.
  - 효과음 타이밍은 `src/components/epic/EpicReveal.tsx`의 `SCRIPTS`를 참고한다 (시크릿: 전조 1.0초, 폭발 3.6초, 초신성 +0.32초).

### 연출 타이밍 참고 (시크릿)

## 성과 확인

- **1순위:** 키워드 댓글 수 (= 링크 요청 수), DM 발송 수, 링크 클릭 수
- **2순위:** 저장·공유 수, 3초 이탈률
- 3초 이탈률이 높으면 훅 문구를 바꾼다. 후보:
  - "이거 뜨면 캡처하세요"
  - "확률 0.05%의 화면"
  - "뽑기 게임 만들다가 연출에 미쳐 버림"
