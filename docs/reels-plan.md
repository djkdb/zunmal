# 말랑 뽑기방 릴스 기획 (한 편, 40초)

제작은 다른 세션에서 한다. 이 문서만 읽고 바로 만들 수 있게 콘티, 화면 글자, 캡션, 촬영 방법을 모두 적었다.

## 목표와 전환 구조

**목표:** 영상을 본 사람이 "나도 해보고 싶다"고 느껴서 **댓글을 남기고 링크를 받아 가게** 만든다.

```
영상 (궁금증 + 욕심) → 댓글 "말랑" → 자동 DM으로 게임 링크 → 플레이 → 시크릿 뽑으면 재공유
```

- **링크는 댓글 키워드로 DM 발송**한다 (ManyChat 또는 Meta 자동 응답, 키워드: `말랑`).
  - 릴스 캡션의 링크는 눌리지 않고, 키워드 댓글이 쌓이면 도달도 오른다.
  - 프로필 링크도 같은 주소로 걸어 둔다.
- **댓글을 남길 이유는 영상마다 두 겹으로 둔다.**
  1. 링크 받기 ("말랑" 댓글)
  2. 참여 질문 (몇 번째 캡슐? 어느 등급? 이름 짓기 등)
- **게임 링크 자리표시자:** `{GAME_URL}` — Cloudflare Pages 배포 주소로 채운다.

## 이 게임에서 사람들이 반응할 재료

영상은 전부 이 재료에서만 뽑는다. 없는 기능은 보여 주지 않는다.

| 재료 | 왜 먹히나 | 게임 속 위치 |
|---|---|---|
| **시크릿 0.05% 연출** (까만 전조 → 혜성 낙하 → 한 점 수축 → 이중 폭발 → 글자 도장) | 확률이 극악이라 "진짜 저게 뜬다고?" 하는 충격과 욕심 | 뽑기 → 시크릿 |
| **말랑이마다 다른 3D 등장** (은하·불사조·유니콘·고래·세라핌) | 수집욕, "내가 뽑고 싶은 애" 고르기 | 신화·시크릿 |
| **등급별 차별화** (일반 → 시크릿으로 갈수록 머신·소리·색이 화려해짐) | 대비가 한눈에 보인다 | 뽑기 결과 |
| **말랑 만지기 소리** (찰박·쭉·뽁) | ASMR, 소리 켜고 보게 됨 | 만지기 탭 |
| **반짝(shiny) 1%** | 같은 캐릭터인데 무지갯빛이라 "레어 중의 레어" | 모든 등급 |
| **귀여운 캐릭터 32종** (복숭아 모찌, 소다 방울, 달토끼 말랑, 꿈빛 유니콘 …) | 캐릭터 호감, "얘 이름 뭐예요" 댓글 | 도감 |
| **미니게임 12종** (말랑 합치기·슬라이스·새총·풍선·기차 …) | 수박게임·과일닌자·앵그리버드처럼 아는 재미라 "뽑기만 있는 게 아니네" | 미니게임 탭 |
| **무료 브라우저 게임** (설치·가입 없음, 홈 화면 추가 가능) | 링크만 누르면 바로 된다는 낮은 진입 장벽 | 전체 |

## 공통 제작 규칙

- **규격:** 1080×1920, 30fps(시크릿 연출 구간은 60fps 권장), **총 40초 안팎**(38~42초).
- **안전 영역:** 위 250px, 아래 400px, 오른쪽 150px에는 글자를 두지 않는다 (릴스 UI에 가려짐).
- **글꼴:** 게임과 같은 **카페24 써라운드**. 흰 글자 + 잉크색(`#2b2233`) 외곽선 + 아래 그림자로 게임 제목과 같은 풍선 글씨.
- **자막:** 존댓말, 한 화면에 한 문장, 짧게.
- **소리가 절반이다.**
  - 게임 효과음(폭발, 종소리 화음, 뽁 소리)을 살리고, 음악은 효과음 아래로 낮게 깐다.
  - 시크릿 수축 직전 **정적 0.3~0.5초**는 음악까지 완전히 끈다.
- **정직하게:**
  - 촬영용으로 결과를 고정해 뽑은 장면을 실제 행운처럼 말하지 않는다 ("첫 판에 떴어요" 금지).
  - "시크릿이 나오면 이렇게 돼요"처럼 연출 공개로 표현한다. 확률 숫자는 사실이니 그대로 쓴다.
- **40초를 버티게 하는 장치:**
  - 3~5초마다 화면 종류를 바꾼다 (미니게임 → 뽑기 → 3D → 만지기 → 암전).
  - 처음에 결말 일부를 보여 주고 "끝까지"로 궁금증을 연다 (플래시 포워드).

## 릴스 한 편: "확률 0.05% 뜨면 생기는 일" (40초)

**한 줄 구성:** 결말 미리보기 → 웹게임 소개 → 미니게임으로 코인 모으기 → 뽑기 등급이 오를수록 화려해짐 → 신화 3D → 만지기로 한숨 돌림 → 시크릿 풀 연출 → 나머지 두 마리 물음표 + 링크 댓글 유도.

### 웹앱이라는 걸 알리는 장치

"앱 설치해야 하나?" 하는 망설임이 링크 요청을 막는 가장 큰 벽이라, 영상 안에서 세 번 알린다.

1. **2.5~6초 — 눈으로 보여 주기:** 인스타 DM 링크를 탭하면 게임이 바로 열리고, 홈 화면에 말랑이 아이콘을 추가해 앱처럼 여는 장면. 앱스토어 화면이 한 번도 안 나온다는 게 핵심이다.
2. **영상 내내 — 작은 꼬리표:** 왼쪽 위(위 250px 아래)에 작은 알약 모양 꼬리표 **설치 없는 웹게임**을 0초부터 40초까지 계속 띄운다. 크림색 바탕 + 잉크 외곽선, 화면 글자보다 훨씬 작게.
3. **36초 — CTA에서 다시:** "설치 없이 링크로 바로 해요"를 '말랑' 요청 바로 앞에 둔다.

- 캡션 첫 줄과 커버에도 "웹게임"을 넣는다.
- 쓰는 표현: "홈 화면에 추가하면 앱처럼 써요" (PWA 지원). 쓰지 않는 표현: "앱 다운로드", "앱스토어".
- **인스타 DM 링크는 인스타 안 브라우저로 열린다.** 게임이 이를 알아채고 주요 버튼 아래에 "브라우저로 열기" 쪽지를 띄운다.
  - 홈 화면 추가는 브라우저(Safari/Chrome)에서만 된다.
  - 영상에는 이 중간 단계를 넣지 않는다 (DM → 게임, 그다음 바로 홈 화면 아이콘 컷).
  - 자동 DM 문구에 한 줄 넣는다: "인스타 안에서 열리면 오른쪽 위 점 세 개 → 외부 브라우저로 열어 주세요. 홈 화면에 추가하면 앱처럼 쓸 수 있어요!"

### 연결 포인트

- **훅의 흑백 정지 장면 = 32초 폭발 장면**과 같은 컷을 쓴다. 시청자가 "아까 그 장면"이라고 알아보게 한다.
- **13.5초의 신화는 3D 연출을 끝까지 보여 준다.** 여기서 "이 게임 연출 진짜네"라는 신뢰가 생겨야 시크릿까지 본다.
- **6초 미니게임 몽타주는 "할 게 많다"는 인상만 준다.** 게임 규칙 설명은 넣지 않는다. 다들 아는 수박게임·과일닌자·앵그리버드 느낌이 한눈에 보이는 순간만 고른다.
- **10.5~13.5초 등급 컷은 점점 짧아진다.** 속도감이 붙다가 13.5초 신화에서 확 느려진다.
- **21.5초 만지기 구간은 쉼표다.** 신화와 시크릿 사이에 템포를 한 번 낮춰야 시크릿 전조의 암전이 세게 느껴진다.
- **40초 → 0초 루프:** 물음표 캡슐 흔들림 끝에 흰 번쩍 한 프레임을 두면, 다시 재생될 때 0초 폭발로 자연스럽게 이어진다.

### 캡션

```
설치 없이 링크로 바로 하는 말랑이 뽑기 웹게임이에요.
미니게임 12종으로 코인 모아서 캡슐을 뽑아요.
확률 0.05%, 시크릿 말랑이가 나오면 화면이 이렇게 돼요.
말랑이마다 등장 장면이 다 달라요. 시크릿은 딱 3마리.
나머지 2마리는 직접 뽑아서 확인해 보세요.

앱 설치도 가입도 없어요. 링크만 누르면 바로 시작하고, 홈 화면에 추가하면 앱처럼 써요.
댓글에 '말랑' 남기면 링크 보내 드릴게요.

#웹게임 #뽑기게임 #가챠 #귀여운게임 #말랑이
```

### 두 번째 댓글 유도 (영상 속 질문 대신 첫 대댓글로)

"여러분 최고 기록은 어디까지예요? 일반/레어/에픽/전설/신화/시크릿"

- 영상에는 CTA를 하나('말랑')만 넣어 헷갈리지 않게 한다.
- 이 질문은 게시 직후 본인 댓글로 달아 대화를 연다.

## 게시 운영

- **시간:** 평일 저녁 8~10시 또는 주말 오후.
- **첫 1시간은 모든 댓글에 답한다.** DM 자동 발송과 별개로 "보냈어요!" 대댓글을 단다.
- **커버 이미지:** 32초의 "시크릿!!" 도장 + 무지개 아치 프레임. 커버 글자는 **확률 0.05%**, 그 아래 작게 **설치 없는 웹게임**.
- **2차 확산:** 시크릿을 실제로 뽑은 플레이어의 캡처를 받아 스토리에 공유한다 (허락 받고).

## 촬영 방법 (제작 세션용)

게임 코드는 이 저장소에 있다. 연출은 브라우저에서 코드로 그리는 것이라, **특정 결과를 강제로 뽑아서 녹화**할 수 있다.

### 원하는 결과 강제로 뽑기

- **원리:** 가챠 엔진은 `Math.random`을 쓰고, 1회 뽑기에 3번 부른다 (희귀도, 캐릭터, 반짝).
- 뽑기 버튼을 누르는 순간에만 `Math.random`을 바꿔치기하면 결과가 고정된다. 저장 데이터만 바뀌고 실제 서비스엔 영향이 없다.

```js
// 페이지에서 실행: seq = [희귀도, 캐릭터, 반짝]
const seq = [0.99996, 0.1, 0.5];
const orig = Math.random; let i = 0;
Math.random = () => seq[i++ % seq.length];
[...document.querySelectorAll('button')].find((b) => b.textContent.includes('1회 뽑기')).click();
Math.random = orig;
```

| 원하는 결과 | seq |
|---|---|
| 시크릿 꿈빛 유니콘 | `[0.99996, 0.1, 0.5]` |
| 시크릿 은하수 고래 | `[0.99996, 0.5, 0.5]` |
| 시크릿 프리즘 세라핌 | `[0.99996, 0.9, 0.5]` |
| 신화 은하 말랑 | `[0.997, 0.1, 0.5]` |
| 신화 불사조 말랑 | `[0.997, 0.9, 0.5]` |
| 반짝 버전 | 세 번째 값을 `0.005`로 |
| 일반 / 레어 / 에픽 / 전설 | 첫 값 `0.3` / `0.7` / `0.9` / `0.98` |

- 코인이 모자라면 `localStorage['malang-gacha-save']`의 `state.coins`를 올린 뒤 새로고침한다.
- 도감을 비우거나 채우고 싶으면 `ownedMalangs`를 직접 편집한다.

### 녹화

- **폰 녹화가 최선이다.** 실제 GPU로 60fps가 나오고 소리도 같이 녹음된다. 가능하면 이걸 쓴다.
- 클라우드 컨테이너에서 찍어야 한다면 그 환경의 Chromium은 3D를 소프트웨어로 그려서 실시간 녹화는 끊긴다. 그러면 **시간을 늦춰 프레임 단위로 캡처**한 뒤 ffmpeg로 이어 붙인다.
  - 기존 스크립트 방식: `performance.now`, `setTimeout`, `requestAnimationFrame`을 k배 느리게 만드는 init script를 넣는다.
  - 뷰포트는 `360×640`, `deviceScaleFactor: 3`으로 두면 1080×1920이 나온다.
  - 실행 옵션: `--use-angle=swiftshader --enable-unsafe-swiftshader --ignore-gpu-blocklist`
  - 캡처한 프레임을 `ffmpeg -framerate 30 -i f%04d.png -c:v libx264 -pix_fmt yuv420p out.mp4`로 합친다.
  - 주의: CSS 애니메이션(화면 띠, 색 반전 프레임, 글자 도장)은 이 방법으로 느려지지 않는다. 필요하면 `document.getAnimations()`로 `playbackRate = 1/k`를 걸어 맞춘다.
  - 폰트는 CDN에서 오므로 막혀 있으면 로컬 woff로 라우팅한다.
- **미니게임(H):** 폰에서 직접 플레이하며 녹화하는 게 가장 자연스럽다. 합치기는 조금 쌓아 둔 상태에서 큰 합치기가 터지는 순간을, 슬라이스는 젤리가 3개 이상 한꺼번에 날아올 때를 노린다.
- **A0·A1 컷은 반드시 실제 폰으로 녹화한다.** 헤드리스 캡처로는 DM 화면과 홈 화면 아이콘을 찍을 수 없다.
  - 폰이 없으면 편집에서 모바일 브라우저 틀(주소창 + `{GAME_URL}` 도메인)을 씌운다.
- **소리:** 헤드리스 녹화로는 소리가 안 담긴다.
  - 폰으로 소리만 따로 녹음하거나, 스피커 출력을 녹음해 편집에서 맞춘다.
  - 효과음 타이밍은 `src/components/epic/EpicReveal.tsx`의 `SCRIPTS`를 참고한다 (시크릿: 전조 1.0초, 폭발 3.6초, 초신성 +0.32초).
  - 편집에서는 게임 연출(약 5.5초)을 콘티 26~36초 구간에 맞춰 늘인다. 모으기 구간만 살짝 느리게(0.8배) 하고, 폭발 이후는 원속도로 둔다.
